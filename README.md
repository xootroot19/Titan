# Foto + Vídeo lado a lado

App web que seleciona uma foto e um vídeo, coloca ambos lado a lado e exporta MP4 (H.264/AAC) preservando o áudio do vídeo. O processamento usa FFmpeg WebAssembly e acontece no navegador.

## Rodar

```bash
npm install
npm run dev
```

## Build

```bash
npm install
npm run build
```

O resultado fica em `dist/`.
